## About

I build booking, payments and healthtech platforms end to end. Over 6+ years I have led production products across sports tech, healthtech and gaming, from API design to React admin consoles and React Native apps.

I am currently a **Software Engineer II at SimStar Asia**, building FastAPI and PostgreSQL services secured with JWT and OAuth2. Earlier, at Techibears, I led 6+ production platforms, including Pi-Play, Just Padel and VirtuScreening.

**Ask me about:** slot-based booking and split payments, serverless AWS architectures, FastAPI and Django REST APIs, and shipping web and mobile clients together.
